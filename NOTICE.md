# Upstream notices · 上游声明

- The theme validation, parsing, defaults and CSS generation in `shared/theme-core.mjs` are ported from `packages/ui/src/lib/theme/` in [OpenChamber v2.8.0](https://github.com/openchamber/openchamber/tree/v2.8.0).
- `panel/builtins.js`, `src/data/builtin-index.json` and `src/data/builtin-defaults.json` derive from the 62 native JSON themes in `packages/ui/src/lib/theme/themes/` of the same release, regenerated by `scripts/gen-builtins.mjs` from the objects of that Git tag. Upstream colors and names are kept; a theme's name does not imply any affiliation with a third party.
- `panel/main.js` inlines the official `@openchamber/sdk@2.8.0` client and the runtime code it needs, so users install no dependencies. The OpenChamber and SDK license follows.
